# CoverShelf

Browse, preview, and swap book covers from Google Books and Open Library — individually or in bulk.

## Install manually

Copy `manifest.json`, `main.js`, and `styles.css` (if present) into `<vault>/.obsidian/plugins/covershelf/`, then enable the plugin in Obsidian.

## Develop

Run `npm install` and `npm run build` from this directory.
